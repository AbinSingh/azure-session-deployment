
# Big picture

We now have all the major building blocks:

                    Azure
                      │
          ┌───────────┼───────────┐
          ▼           ▼           ▼
         ACR      Managed Redis   AKS
          │                         │
          │ image                   │
          ▼                         ▼
   session-api:a2              FastAPI Pod
                                    │
                                    ▼
                              Kubernetes Service
   

In A7 we'll deploy one FastAPI replica and expose it through a Kubernetes Service.

We'll initially use LoadBalancer because it gives us a simple Azure public IP for 
learning/testing. Later we'll replace this with a more production-oriented ingress architecture.

# A7.1 — Create a Kubernetes namespace

    kubectl create namespace session-app

# A7.2 — Create the Redis configuration Secret

We'll use a Kubernetes Secret for the credentials.

kubectl create secret generic redis-credentials --namespace session-app --from-literal=REDIS_PASSWORD="$REDIS_PASSWORD"

kubectl get secrets -n session-app

# A7.3 — Create the Deployment
    k8s/
    ├── deployment.yaml
    └── service.yaml

# A7.4 — Apply the Deployment

    kubectl apply -f k8s/deployment.yaml

# A7.5 — Check the Deployment

    kubectl get deployments -n session-app

# A7.7 — Create the Kubernetes Service

    k8s/service.yaml
