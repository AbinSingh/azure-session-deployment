# TLS connection

    A successful TLS connection should show certificate information and something similar to:

    CONNECTED
    ...
    Protocol  : TLSv1.2
    ...
    Verify return code: 0

The exact output will vary. But there's another very useful test

Because you're ultimately running Python/redis-py, let's test TLS using Python itself.

**Run this on your Windows machine:**

    python -c "import socket,ssl; s=socket.create_connection(('aks-practice-redis.eastus.redis.azure.net',10000),10); print('TCP OK'); c=ssl.create_default_context().wrap_socket(s,server_hostname='aks-practice-redis.eastus.redis.azure.net'); print('TLS OK:',c.version()); c.close()"

If successful, you'll get something like:

    TCP OK
    TLS OK: TLSv1.2

This test is particularly valuable because it uses Python's TLS implementation, which is much closer to what your redis-py container is doing.
