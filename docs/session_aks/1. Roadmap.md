# One Important Improvement Before A1

Your current redis_client.py probably contains something like:

redis.Redis(
    host="127.0.0.1",
    port=6379,
    ...
)

That is fine for your session-redis-local branch. But it won't work in AKS.

Inside an AKS Pod:127.0.0.1 means: This FastAPI Pod itself.

It does not mean your Azure Redis server.

So our first AKS change should be configuration-driven:

                Environment
                     │
        ┌────────────┴────────────┐
        ▼                         ▼
    Local machine              AKS
        │                         │
        ▼                         ▼
127.0.0.1:6379             Azure Redis endpoint

Same application. Different configuration. That's another very important enterprise principle:

Configuration belongs outside the application code.
