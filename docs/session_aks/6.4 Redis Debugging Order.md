# Azure Managed Redis → Docker → FastAPI Debugging Flow

Step	                                                    Test / Action	                    Layer / Area	                                                    Purpose	Result
1	Azure Portal → Networking → Public network access	Azure infrastructure	        Ensure your local machine is allowed to reach Redis over the public network	    ✅ Enabled
2	nslookup <redis-host>	                                    L7 / DNS	            Verify Redis hostname resolves to an IP address	                                ✅ Resolved 172.212.57.138
3	Test-NetConnection <redis-host> -Port 10000	                L4 / TCP	            Verify your machine can establish TCP connectivity to Redis port 10000	        ✅ TcpTestSucceeded: True
4	Python socket + ssl test on Windows	                        TLS / L6-ish	        Verify TLS handshake works independently of Redis client/application	        ✅ TLS 1.3
5	memurai-cli --tls	                                        Redis client + TLS	    Attempt an actual Redis client connection from Windows	                        ❌ TLS issue with Memurai CLI
6	Docker container → Python TCP/TLS test	                Docker networking + TLS	    Determine whether Docker can reach Redis independently of FastAPI	            We then isolated further
7	Docker container → redis-py + PING	                Redis client / authentication	Test the complete Docker → Redis connection, including TLS and authentication	    ✅ True
8	Rebuild/update Docker image	                        Application/container	        Ensure the container contained the latest FastAPI/Redis code	                    ✅ Fixed
9	Run FastAPI container	                            Application	                    Verify actual application can use Redis	                                            ✅ Working
